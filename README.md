# 📌 Project Overview

AI Language Translator is a Generative AI web application developed using **Python**, **Flask**, and the **Google Gemini API**.

The application allows users to translate text into multiple languages using Google's Gemini Large Language Model. Users simply enter text, choose a target language, and receive an AI-generated translation instantly.

The project demonstrates how Generative AI can solve real-world communication challenges through intelligent and context-aware language translation.

---

# 🎯 Chosen Use Case

## AI Language Translator

Language barriers often make communication difficult in education, travel, business, and everyday life.

This application enables users to translate text between multiple languages—including **English ↔ Telugu**—while preserving the original meaning and tone.

# 💡 Prompt Engineering

The application uses a structured prompt to improve translation quality.

### Prompt Used

```text
You are a professional language translator.

Translate the following text into the selected language.

Rules:
- Preserve the original meaning.
- Preserve the tone.
- Do not explain anything.
- Return only the translated text.
```

### Why This Prompt?

- Produces accurate translations
- Preserves sentence meaning
- Maintains writing style and tone
- Prevents unnecessary explanations
- Generates clean AI responses
